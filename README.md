Chat levels, leaderboards, game-server status and amulet reactions to announcements and update posts.

## Run locally

Requires Node 22.13–22.x and your own Discord bot installed in a test server. Copy `scripts/bot.env.example` to `.env` and fill in your IDs, token-file path and database path.

```sh
./run.sh
```

Bot setup and permissions are described in `docs/operations.md`.
